About the programme

The Bachelor of Web Engineering is a three-year programme that teaches students how to build modern websites and web applications. Students learn both the front-end (HTML, CSS, JavaScript) and the back-end (Node.js, Express, databases). Every semester ends with a team project built for a real client.
